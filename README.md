# 1. 문서 개요
> 본 문서는 프로젝트 진행 과정을 나타낸 문서임. 암튼 그럼

# 2. 진행 과정
- 영상 로딩 및 첫 프레임 출력
- 영상 재생
- 영상 배경 제거
- 영상 뒤처리
- 객체 탐지 및 객체 추적 박스 생성
- 객체 추적 박스에 id 등록
- 박스 이동경로 표시
- 일시정지, 저장 구현
- FPS 표시
- 타겟 검출
